# 独立翻前研究工具行为规格

这是一份独立实现的工程规格。HRC 静态发现为需求来源之一；本文件不包含或要求复用 HRC 代码、数据表、素材及其内部格式。下述是实现必须说明的行为和验收条件，不代表这些功能已全部实现。

## 研究目标与模型

建立包含弃牌、过牌、跟注、多尺寸加注、再加注、全下的有限翻前行动树，并在指定模型下学习每个决策点的手牌行动概率。这里的「完整翻前树」是针对用户选定的有限尺寸集合完整展开，不是穷尽所有连续筹码尺寸。

必须把三层信息分别呈现：

1. 规则：哪些动作合法，筹码如何流动，何时进入摊牌。
2. 抽象：允许哪些尺寸、多少层加注、哪些 flat 线路、如何评估翻后延续。
3. 求解质量：采样量、信息集访问量、策略变动与有效验证结果。

若第一个版本使用翻前结束后自动发完公共牌的收益，设置与结果都应标明「翻后过牌到底」。这种模型足以形成可计算的完整翻前有限博弈，但不能声称获得现代 HRC 深筹码策略精度。若以后添加翻后 continuation solver，需要明确其抽象、训练来源与误差。

## 输入

- 玩家按固定座位身份排序；显示位置标签；HU 时按钮兼 SB，先行动，BB 后行动。
- 筹码指发牌前、未扣盲注/ante 的金额。默认使用 bb 为显示单位，内部使用稳定精度表示。
- SB、BB、ante 类型和值；各玩家范围。初始范围默认所有合法两张私牌，支持对 169 个手牌类别赋 0–100% 权重。
- 分层尺寸：开池以 bb 为主，再加注可用相对前次 raise-to 倍数；全下为独立候选。
- 跟注限制、可选 SB complete、冷跟限制、closing-call 例外、最大加注深度/节点资源限制。
- 迭代/采样预算与固定种子；收益模型及其局限。

输入不能有 NaN、无穷、负筹码、SB > BB、超过有效范围的权重或全部为零的某玩家初始范围。阻挡后无合法联合发牌时，应拒绝计算并解释冲突。

## 规则状态与行动

每个状态至少保存：座位身份、剩余筹码、该轮投入、总投入、folded/all-in 状态、当前最大投入、最近一次完整 raise 增量、仍需行动的玩家、加注权、行动历史。先投入 ante，再投入盲注，均不超过自身可用筹码。

- **Fold：**面临有效下注时可弃牌，投入留在底池。
- **Check：**无须补筹码时可过牌。BB 不能因为其他玩家都 limp 而被跳过。
- **Call：**补到当前下注额或投入剩余全部筹码；不足额跟注形成 all-in call。
- **Raise：**以 raise-to 总额表示；付出总额减本轮已投入。正常最小加注必须满足最近完整 raise 的增量。
- **All-in：**可为 call 或 raise。低于正常最小 raise 的短全下不能被简单当成完整加注；应分别跟踪谁已行动及其再次加注权。
- **无人可回应：**只剩一名未全下玩家且无欠款时结束下注；不能继续生成无对手可响应的加注。
- **终局：**仅一名未弃牌玩家时直接获底池；否则所有应行动玩家完成且投入已匹配，结束翻前并调用 continuation 模型。

非全下尺寸需落在合法区间；相同落点去重。超过有效对手筹码的未被跟注部分需要返还，不能凭空进入可赢取底池。边池按投入层级分割，每个边池只由达到该投入层且未弃牌玩家争夺，平局等分。

以上按通用扑克规则独立实现，不声称与本机 HRC 的所有特殊规则逐条匹配。

## 范围与结果语义

显示 13×13 的 169 类手牌：对子、同花、非同花。实际发牌从 1,326 个两牌组合生成：对子 6、同花 4、非同花 12 组合。权重汇总必须按组合数加权，不能简单平均 169 个格子。公共牌、其他玩家私牌和已折叠手牌应遵守同一副牌的无重复约束。

每个信息集应由玩家自己的手牌信息与公共行动历史索引，不能让决策策略读取其他玩家私牌。对方私牌可以用于摊牌收益计算，不能泄露给该节点的策略索引。

一个选定节点显示：行动路径、行动玩家、底池/有效筹码、合法行动、各手牌的混合策略、各行动总体频率、可用时的 EV、样本访问情况。把「起始范围权重」「到达节点的条件范围」「该手牌选择各行动的概率」区分开。

未访问或样本稀少的手牌不能伪装成已收敛策略。默认均匀概率可以作为初始化，但需注明初始化或低覆盖状态。EV 若依赖有限样本，也应标明估计性质。

## 求解与质量说明

独立选择并实现公开的 CFR / MCCFR 家族算法，保留种子、配置、遍历数和版本。平均策略与当前策略的用途应分开；若提供平均策略结果，应保证其累计权重与采样估计器匹配。

算法在特定有限博弈中的理论性质不能直接转述为无限扑克或任意多人游戏的精确 Nash 保证。策略变动只能叫策略变动指标。未实现 best-response exploitability 时，不得把策略变动值标成 Nash gap、exploitability 或精确误差。

节点锁定应冻结指定行动策略并验证概率和为 1；之后重算受影响策略。取消任务应可停止并给出已经完成的进度。若实现恢复，只有配置与算法状态兼容时可继续，避免把新树误接到旧 regret 状态。

## 验收案例

| 案例 | 应观察到的结果 |
|---|---|
| HU 盲注与行动 | SB/按钮先行动，BB 后行动；盲注正确扣除 |
| SB limp、BB check | 补齐差额后 BB 仍有行动机会，check 后进入 continuation |
| raise-call | 筹码按 raise-to 解释；不能把总额重复扣除 |
| 开池与再加注 | 前一次完整加注增量决定新的 minimum raise |
| 短筹码 all-in call | 不强制补足欠款，不出现负筹码 |
| 短 all-in raise | 未重新开放的玩家仍可 fold/call，但不能非法 re-raise |
| 多人不同筹码全下 | 正确建立主池/边池，全部资金守恒 |
| 全部弃牌 | 获胜者净收益等于他人已投入；未跟注超额返还 |
| 7 张牌评价 | 能比较高牌至同花顺；可正确平局 |
| 一副牌 | 任意发牌样本不存在重复牌 |
| 169 类权重 | 满范围对应 1,326 组合；AA 6、AKs 4、AKo 12 |
| 费用为零的终局 | 所有玩家净收益之和为 0 |
| 策略概率 | 每个手牌各行动概率有限、非负且和为 1 |
| 相同配置与种子 | 在同一算法版本/执行方式下可复现实验 |
| 受控小博弈 | 在 Kuhn 等有已知解的模型验证更新与平均策略逻辑 |
| 资源上限 | 构建超预算时明确报限，不静默删除线路后宣称完整 |

需要与 HRC 比较时，应保存两端完全一致的筹码、尺寸树、范围、收益与 continuation 配置，再进行受控数值实验。仅凭界面相似或使用同一算法家族不构成等价性证据。
